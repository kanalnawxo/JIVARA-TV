ExoPlayer - بافەری زیاتر و کوالێتی بەرز بۆ هێڵی سست
=====================================================

ئەمە کۆدی ناوەکی (Java/Kotlin)ـە و لە پڕۆژەی APK دا زیاد دەکرێت (هەمان شوێنی دروستکردنی ExoPlayer لە MainActivity).
لە ڕێگەی JavaScript (index.html) ناتوانرێت ExoPlayer بافەر بکرێت، بۆیە بەبێ ئەم گۆڕانە ExoPlayer هەمان ڕێکخستنی بنەڕەتی بەکاردێنێت.

ئەوەی دەکات:
  - ٣٠ چرکە لانیکەم و تا ٢ خولەک بافەر دەکات (کاتێک هێڵ باشە پڕ دەبێتەوە، کاتێک سستە پێشتر پڕکراوەکە دەخوات)
  - هەمیشە بەرزترین کوالێتی هەڵدەبژێرێت (بەرز نایەتەخوارەوە)
  - دوای وەستان بۆ بافەر، زیاتر چاوەڕێ دەکات تا دووبارە نەوەستێت

تێبینی: ئەگەر هێڵی بەکارهێنەر لە بیتڕەیتی (bitrate) ڤیدیۆکە کەمتر بێت، ڤیدیۆکە ناچار دەوەستێت بۆ بافەر.
ئەمە سنووری فیزیکییە و بەبێ دابەزاندنی کوالێتی ناتوانرێت لابرێت.

--- کۆدی Media3 ---

import androidx.media3.exoplayer.DefaultLoadControl;
import androidx.media3.exoplayer.ExoPlayer;
import androidx.media3.exoplayer.trackselection.DefaultTrackSelector;

DefaultLoadControl loadControl = new DefaultLoadControl.Builder()
    .setBufferDurationsMs(
        30_000,    // minBufferMs: لانیکەم ٣٠ چرکە بافەر
        120_000,   // maxBufferMs: تا ٢ خولەک پێشتر
        2_500,     // bufferForPlaybackMs: ٢.٥ چرکە پێش دەستپێکردن
        8_000)     // bufferForPlaybackAfterRebufferMs: ٨ چرکە دوای وەستان
    .setPrioritizeTimeOverSizeThresholds(true)
    .build();

DefaultTrackSelector trackSelector = new DefaultTrackSelector(context);
trackSelector.setParameters(
    trackSelector.buildUponParameters()
        .setForceHighestSupportedBitrate(true)   // بەرزترین کوالێتی، نەک خوارتر
        .build());

ExoPlayer player = new ExoPlayer.Builder(context)
    .setLoadControl(loadControl)
    .setTrackSelector(trackSelector)
    .build();

ئەگەر دەتەوێت هەندێک ئاسانکاری هەبێت (کوالێتی خۆکار بەپێی هێڵ)، دێڕی setForceHighestSupportedBitrate لاببە.
