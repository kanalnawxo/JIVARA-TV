VLC Player - کۆدی ناوەکی (Android) بۆ پڕۆژەی JIVARA TV
=====================================================

بۆچی پێویستە؟
ئەپەکە لەناو WebView کار دەکات و WebView ناتوانێت ڕاستەوخۆ ئەپی VLC بکاتەوە.
بەشی وێبی ئەپەکە (index.html) پێشتر ئامادەیە و بانگی ئەم فەنکشنە دەکات:

    AndroidPlayer.openExternal(url, "org.videolan.vlc")

تا ئەم فەنکشنە لە MainActivity زیاد نەکرێت، ئەگەر «VLC Player» هەڵبژێریت،
ئەپەکە نامەیەک نیشان دەدات و ExoPlayer بەکاردێنێت (هیچ شتێک ناشێوێت).

١) لە MainActivity.java: ناو کلاسی NativeBridge (ئەو کلاسەی @JavascriptInterface play/pause/stop ی تێدایە)
   ئەم فەنکشنە زیاد بکە. activity = ئەو Activity ـەی کە NativeBridge ی تێدایە
   (ئەگەر ناوەکەی جیایە، بیگۆڕە):

    @JavascriptInterface
    public boolean openExternal(String url, String pkg) {
        try {
            Intent i = new Intent(Intent.ACTION_VIEW);
            i.setDataAndType(Uri.parse(url), "video/*");
            if (pkg != null && !pkg.isEmpty()) i.setPackage(pkg);
            i.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
            if (i.resolveActivity(activity.getPackageManager()) == null) return false; // VLC دانەمەزراوە
            activity.startActivity(i);
            return true;
        } catch (Exception e) {
            return false;
        }
    }

   import ـەکان:
    import android.content.Intent;
    import android.net.Uri;

٢) ئەگەر targetSdkVersion = 30 یان زیاتر بوو، لە AndroidManifest.xml (لەناو <manifest>):

    <queries>
        <package android:name="org.videolan.vlc" />
    </queries>

   (ئێستا targetSdkVersion = 28 ـە و پێویست نییە.)

٣) APKەکە دووبارە بنیات بنێ و بە هەمان کلیلی واژۆ واژۆی بکە.

تێبینی: ئەگەر مەبەستت لە «Android Player» پلەیەری سیستەمی ئەندرۆید (دەرەکی) بوو، نەک ئەوەی ناو ئەپ،
هەمان فەنکشن دەتوانێت بیکاتەوە بە pkg = "" (ئەو کاتە ئەندرۆید لیستی پلەیەرەکان نیشان دەدات).
